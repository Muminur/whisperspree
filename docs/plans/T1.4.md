# T1.4 Local Whisper engine plan

## Scope

Implement the local `SpeechRecognizer` in `src-tauri/src/asr/local_whisper.rs` against the normative FR-1.1.b contract. The decoder boundary is injected so unit tests never load a model or perform network/OS work; a production adapter can wrap `whisper-rs` once its build configuration is available.

## Architecture

- Define the PRD §9.3 `SpeechRecognizer`, `AsrConfig`, `AsrEvent`, `FinalTranscript`, and `WordTiming` shapes in the ASR module (or reuse existing equivalents without changing their wire meaning).
- Keep a session-local pending buffer of post-VAD 16 kHz mono samples. Close non-overlapping windows at 4,000 ms, at 700 ms endpoint silence with at least 600 ms speech pending, or during `finalize`.
- Decode on a serialized blocking worker. Capture may continue into the next buffer; at most two windows wait. If the queue is full, concatenate pending windows rather than starting concurrent whisper contexts.
- Pass the prior decoded text suffix, capped at 200 Unicode characters, after the dictionary-bias prompt as `initial_prompt` for the next window.
- Map decoder token timestamps to whitespace words with monotonic millisecond offsets from utterance start. Emit `transcript:segment` events and return the accumulated final transcript.
- Track consecutive decode wall-time ratios. Two decodes over 1.5× window duration emit recoverable `ASR-SLOW`; for tiers above `base`, persist a one-tier-lower effective model for the next session.
- Keep whisper-specific loading/decoding behind an injected `LocalDecoder` trait; production now owns one `whisper-rs` context through `WhisperRsDecoder`, while tests use a deterministic fake.

## Tests before implementation

- `fr_1_1_window_closes_at_4s`
- `fr_1_1_window_closes_on_700ms_endpoint_after_600ms_speech`
- `fr_1_1_finalize_flushes_short_pending_window`
- `fr_1_1_windows_are_non_overlapping_and_decode_serialized`
- `fr_1_1_queue_depth_two_concatenates_overflow`
- `fr_1_1_initial_prompt_carries_last_200_chars_after_dictionary_bias`
- `fr_1_1_word_timings_are_monotonic_and_cover_text`
- `fr_1_1_decode_slow_twice_emits_asr_slow_and_downgrades_next_session`
- failure-path tests for missing/corrupt decoder and no-model (`ASR-NOMODEL`), with no network/model download.

## Risks and constraints

- Do not add a dependency outside PRD §4 without updating `docs/DEPENDENCIES.md`.
- `whisper-rs` builds are platform/toolchain-sensitive; keep it behind the decoder boundary and use an ignored opt-in real-model test (`WHISPERSPREE_TEST_MODEL`).
- Decode ordering and cancellation must not hold an audio/IPC lock across blocking work.
- T1.4 does not implement session state transitions, cloud ASR, or SM-4 tail ownership; those remain T1.5/T3.1.
