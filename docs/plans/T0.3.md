## RULING (gates the tests) — CONFIRMED with one refinement
The §14 set is closed (pinned by the `code()`-string test). Inventing a 15th code is forbidden (CLAUDE.md §7). Therefore:
- **(a) settings.json I/O failure → `DB-IO`.** Confirmed. Recovery col "non-blocking toast; dictation still injected" (§14 L924) fits local-persistence loss; broaden its *condition* from "sqlite" to "local persistence (SQLite **or** settings.json)". Recoverable=true already (Q6) — correct, a settings-write failure must not crash the session.
- **(b) keychain set/get/delete failure → `DB-IO`.** Confirmed, same rationale — it is *local* persistence, so `LLM-AUTH`/`NET-STREAM` (provider-auth, network) are wrong; those fire later when the key is *used*. - **(c) invalid `update_settings` value → NOT an error.** Confirmed. `validate()` **clamps** out-of-range numerics and **rejects-by-ignoring** malformed enums/accelerators (previous valid value survives the deep-merge); `update_settings` returns the resulting `Settings`. Matches §8.3 "unknown fields preserved on rewrite" tolerance. Refinement: the *validated/clamped* value is what gets **persisted**, so a bad patch never corrupts the file.

## Algorithm
1. **get():** read `settings.json`; if absent → `Settings::default()` (do not yet write). Parse to `Value`, `validate`, deserialize→`Settings`. Parse failure → `Error::DbIo`.
2. **update(patch):** read current raw `Value` (or default Value) → `deep_merge(base, patch)` → `validate(base)` → `atomic_write(base)` → `serde_json::from_value(base)` → return `Settings`. **Persist the merged raw Value** so unknown keys survive.
3. **deep_merge:** if both `base[k]` and `patch[k]` are objects → recurse; else `base[k]=patch[k].clone()` (present key overwrites, incl. explicit `null`; **absent key untouched**; **arrays replaced wholesale**).
4. **validate:** clamp `postprocess.timeoutMs`≥1, `history.retentionDays`≥0, `injection.typeThresholdChars`≥0, `restoreClipboardDelayMs`≥0; drop `mode`∉{auto,local,cloud}, `hotkey.mode`∉{push_to_talk,toggle}, non-string `pushToTalkKey`/`toggleCombo` (reject-by-ignore → prior value survives). Unknown keys left intact.
5. **atomic_write:** serialize pretty → write `settings.json.tmp` in same dir → `set_permissions(0o600)` → `sync_all` → `rename` over `settings.json` → best-effort dir fsync. Any `io::Error` → `Error::DbIo` (Q8-a marker).
6. **key commands:** map `Provider`→account literal → delegate to `KeyStore`; any keyring `Err`→`Error::DbIo` (Q8-b marker); `has`=`get().is_some()`.
