# Plan — T2.2 `[DC]` Injection service (FR-1.4)

Status: active · Owner: Opus · Deps: T1.5 ✓
Normative refs: PRD FR-1.4, AC-1.4, EC-1.4, §9.1 (`test_injection`, `inject:done`), §9.3 (`Injector`), §12 P-5/P-6, §14 (INJ-FAIL, SEC-FIELD, AX-PERM), R-3/R-4 risk register, QA-2.

## Current state

- Policy chain (`inject/mod.rs`) complete + 10 integration tests (`tests/injection.rs`): paste/type/clipboard-only selection, non-text guard, save/restore, user-copy-wins guard, AX-failure fall-through, secure/no-target clipboard-only, restore-failure surfacing.
- Coordinator (`pipeline/session.rs`): `Injecting` state, `processed()` computes ClipboardOnly-vs-Normal from `target.secure_input`, unknown-target fallback, `inject_done()`. Emits `CoordinatorEvent::InjectionReady` — **consumed nowhere in production**.
- Gaps (reviewer-confirmed): native revision is a content hash, RTF never captured, non-text detection image-only via arboard, empty restore writes `""`, inter-key delay ignored, failed paste can leave ⌘ pressed, `MacPasteVerifier` always `None`, `secure_input` hardcoded `true` (production can never type/paste!), no managed `Injector` in `IpcState`, `test_injection` TODO, Final→Injecting→`inject:done`→Idle unwired, secure outcomes carry no explicit history-suppression flag, AX-unavailable fallback unspecified.

## Decisions

1. **Native pasteboard via `objc2` 0.6 + `objc2-foundation` + `objc2-app-kit` 0.3.2** (cfg macos). Already vendored transitively by tauri/wry → lockfile-stable; declared as direct deps with `docs/DEPENDENCIES.md` rows (justification: arboard exposes neither `changeCount`, nor `public.rtf`, nor `clearContents`; FR-1.4 needs all three — "compare arboard change count / content hash" is satisfied by the stronger native count; AX/Carbon checks are PRD §4-sanctioned OS integration).
   - `revision` = `NSPasteboard.changeCount` (strictly monotonic; fixes identical-content re-copy race R-4).
   - Snapshot captures `public.utf8-plain-text` + `public.rtf`; classification from the pasteboard types array decides Text vs NonText vs Empty (pure fn, headless-tested).
   - `restore(Empty)` → `clearContents()` (true clear, not `set_text("")`).
2. **Typist**: `type_text` calls `enigo.set_delay(inter_key_delay_ms)` before `text()` (docs.rs: `Enigo::set_delay(u32)` is the supported per-keypress knob); `paste()` presses ⌘, clicks V, and **always releases ⌘** before propagating a click failure.
3. **Secure/focus provider** (`context/macos.rs`): `secure_input = IsSecureEventInputEnabled() || (AX trusted && focused element role == AXTextField-with-secure-flag)`. Carbon probe is permission-free (extern FFI, no dep); AX role check is best-effort per EC-1.4 — untrusted/unavailable AX never fails injection and falls back to the Carbon answer alone. This replaces the hardcoded `secure_input: true` so production typing becomes reachable while staying conservative.
4. **Own-window / no-target**: frontmost bundle id == own identifier (tauri.conf.json) → `target_is_valid=false` → clipboard_only (FR-1.4 focus-loss rule). Pure decision fn `resolve_inject_context(AppContext, ax_trusted) -> InjectContext` is headless-tested; adapters stay thin.
5. **Managed injector**: `IpcState` holds `Arc<dyn Injector>`; macOS factory wires `InjectionService{MacClipboard, MacTypist, MacPasteVerifier}`; deterministic seam for tests. `test_injection(sample)` builds context from the live provider, injects, returns `{method}`; SEC-FIELD resolves to `method:"clipboard_only"` (§14 recovery = notice + clipboard-only, not an error); remaining failures map through the existing ApiError codes.
6. **Session wiring**: runtime consumes `InjectionReady` → emits `Injecting` state → calls injector with final transcript → emits `inject:done {sessionId, method}` → coordinator `inject_done()` → Idle. Secure-field outcomes carry explicit `persist_history:false` on the internal outcome (history writer itself lands with T6.1; P-5 requires the suppression signal to exist now).
7. **Test doubles stay at network/OS-permission boundaries only** (CLAUDE.md §3): policy logic goes pure/double-tested; native reads/synthesis are exercised by QA-2 manual sheets; no network, no model downloads.

## TDD slice order (each slice: red → green → full-suite green)

A. **Policy hardening** (pure): threshold boundary exactly 200 chars types; empty text types without touching clipboard; secure/no-target outcomes expose `persist_history=false`; user-copy-wins re-asserted under changeCount semantics.
B. **Native clipboard fidelity**: pure `classify_pasteboard_types` matrix (utf8/rtf/tiff/png/file-url/mixed/none); `RestoreAction::{Clear, SetText}` decision incl. RTF pair; adapter rewired to changeCount + rtf + clearContents.
C. **Typist correctness**: delay wired; unconditional ⌘ release (source-contract test + QA-2).
D. **Secure/focus provider**: `resolve_inject_context` matrix (carbon-secure, ax-role-secure, ax-untrusted-degrades-to-carbon, own-window, no-frontmost); adapter uses Carbon FFI + best-effort AX.
E. **Managed injector + `test_injection`**: IpcState seam; command dispatch tests over MockRuntime doubles (secure→clipboard_only `{method:"clipboard_only"}`, success→actual method, INJ-FAIL path).
F. **Runtime wiring**: InjectionReady consumed; state/event order Injecting → inject:done → Idle; secure outcome suppresses history flag end-to-end; duplicate/failed injection cannot wedge the machine (Error→Idle preserved).
